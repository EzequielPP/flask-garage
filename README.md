# 🚗 Flask Garage Management System

Un sistema de gestión de inventario automotriz moderno y funcional, desarrollado con **Python** y **Flask**. Esta aplicación permite administrar una flota de vehículos de manera eficiente, ofreciendo herramientas de análisis de datos y una interfaz de usuario optimizada.



## 🌟 Características Principales

* **Gestión CRUD Completa:** Registro, visualización, actualización y eliminación de vehículos en tiempo real.
* **Panel de Estadísticas:** Visualización dinámica del total de flota y promedio de kilometraje.
* **Buscador Inteligente:** Filtro instantáneo por marca o modelo mediante JavaScript.
* **Sistema de Alertas:** Notificaciones automáticas para vehículos que requieren mantenimiento (cada 10,000 km).
* **Interfaz Profesional:** Diseño de dos columnas utilizando **Bootstrap 5**, totalmente responsivo.
* **Modo Oscuro:** Soporte nativo de apariencia clara/oscura para mejorar la experiencia de usuario.
* **Persistencia de Datos:** Base de datos robusta utilizando **SQLite3**.

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python 3 + Flask
* **Base de Datos:** SQLite3
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
* **Framework CSS:** Bootstrap 5.3 + Bootstrap Icons
